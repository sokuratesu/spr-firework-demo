How video selection works

When a page shows a single video (Thank You page)

Firework always shows the most recently uploaded video that matches the page's hashtags. When you upload a new setup video for BRAVIA 3 and tag it correctly, it automatically replaces the old one on the Thank You page. No action needed.

When a page shows multiple videos (Video Hub, Locker)

All videos matching the hashtags appear, sorted by upload date (newest first). Adding a new video pushes it to the top of the list.

What if I upload 2-3 new videos per month?

Each new video just needs the correct hashtags. It flows to the right pages automatically. The previous video stays in the library and still appears in multi-video sections (grids, carousels). On single-video pages, the newest one takes over.

Optional: showing a specific older video

If you ever need to show a specific older video instead of the newest one on a single-video page, we have a solution available using a dedicated "pinning" tag. This is a small addition we can set up if needed. In most cases, the default behavior (newest video appears) is exactly what you want.

Key takeaways

After launch, you manage all video content from the Firework dashboard. The pages never need code changes.

Each page has a fixed hashtag filter built into the code. You control which videos appear by managing their hashtags in Firework.

To add new content, upload the video and tag it correctly. It flows to all matching pages automatically.

Hashtags can be updated individually or in bulk at any time.
