Test 1

Video Duration via content-ready Event

Geevan confirmed: don't use the internal embed feed API. Instead, listen for the fw:embed-feed:content-ready event — the payload contains a video object with duration.

What to check: When the Firework embed below loads, the event log should capture the content-ready event and display the duration for each video. If it works, Liam can use this in React to render duration badges.
// Geevan's recommended approach
document.addEventListener('fw:embed-feed:content-ready', (e) => {
  const videos = e.detail?.videos || e.detail?.feed_items;
  videos?.forEach(v => {
    console.log(v.caption, v.duration);
  });
});

Custom Cards with fw-storylink Popup Trigger

Geevan provided the fw-storylink component — wrap any custom element and clicking it opens the Firework popup player for that specific video ID. This lets us build our own thumbnail cards with duration badges and still use the Firework player.

What to check: Click any of the custom cards below. Each wraps an image in <fw-storylink> with a specific video ID. If it works, the Firework popup should open and play that video.
// Geevan's fw-storylink pattern
<fw-storylink channel="sony_electronics_us" video="VIDEO_ID">
  <img src="thumbnail.jpg" />
</fw-storylink>

Test 3

dock="true" — Auto-Float on Scroll

Geevan clarified: pip="true" is for persisting the player across page navigations. For auto-floating when the video scrolls out of view, use dock="true" instead.

What to check: Play the video below, then scroll down past it. The player should automatically shrink to a floating widget in the corner. We're testing with dock="true" on a StoryBlock.
// What we had (wrong):
<fw-storyblock pip="true" ...>

// What Geevan recommends (correct):
<fw-storyblock dock="true" ...>
